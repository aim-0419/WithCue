**대상 운동:** Neck Rotation / Shoulder Front Raise / Bird Dog / Straight Leg Raise

## 1. 동작 단계 (Phase) 정의

### 1.1 공통 Phase 체계

모든 운동에서 공통으로 사용하는 phase 레이블. 각 processor의 `_estimate_phase()`가 매 프레임마다 판정한다.

| Phase | 정의 | 라벨링 기준 |
|---|---|---|
| `unknown` | YOLO 감지 실패 또는 분석 불가 상태 | 필수 관절 중 하나 이상이 미감지 |
| `idle` | 비활성 상태. 운동 시작 전 또는 완전 종료 후 대기 | 주 동작 관절 각도가 기준 범위 내, 움직임 없음 |
| `ready` | 시작 자세 완료. 움직임은 없으나 운동 준비 완료 | `idle`보다 자세가 잡힌 상태. 첫 프레임 직전 |
| `raising` | 주 동작 진행 중 (올리는 방향) | DTW 기준 동작 대비 진행률이 증가하는 구간 |
| `peak` | 최대 가동범위 도달 지점 | 주 특징값이 최댓값 부근. DTW ref_progress > 0.85 |
| `lowering` | 복귀 동작 진행 중 (내리는 방향) | DTW 기준 대비 진행률이 감소하는 구간 |
| `transition` | raising/lowering 판단이 불명확한 전환 구간 | 방향 전환 직후, DTW 유사도가 낮은 구간 |

> 라벨 우선순위: `unknown` > `idle` > `ready` > `peak` > `raising` > `lowering` > `transition`
> peak를 raising/lowering보다 먼저 판정해 최대 도달 구간이 묻히지 않도록 한다.

### 1.2 Neck Rotation 전용 Phase

목 회전 운동은 좌우 교차 구조여서 추가 단계가 필요하다. processor 내부 상태(`rep_phase`)와 DTW 분석 phase가 분리되어 있다.

**processor 내부 상태 (rep_phase)**

| 상태 | 정의 |
|---|---|
| `idle` | 운동 시작 전 중립 자세 |
| `first_turn` | 첫 번째 방향(좌 또는 우)으로 회전 진행 중 |
| `center_return_1` | 첫 회전 후 중심으로 복귀 중 |
| `second_turn` | 반대 방향으로 회전 진행 중 |

**DTW 분석 phase**

| Phase | 정의 |
|---|---|
| `turning_right` | 오른쪽 회전 진행 중 |
| `turning_left` | 왼쪽 회전 진행 중 |
| `center` | 중심 복귀 구간 |
| `peak` | 최대 회전 도달 |
| `transition` | 방향 전환 불명확 구간 |
| `unknown` | 감지 실패 |

### 1.3 운동별 Phase 매핑 요약

| Phase | Shoulder Front Raise | Bird Dog | Straight Leg Raise | Neck Rotation |
|---|---|---|---|---|
| `idle` | — | ✅ (별도 state 관리) | — | ✅ |
| `ready` | ✅ | ✅ | ✅ | — |
| `raising` | ✅ 팔 올리는 구간 | ✅ 팔/다리 올리는 구간 | ✅ 다리 올리는 구간 | — |
| `peak` | ✅ 최대 올림 | ✅ 최대 올림 | ✅ 최대 올림 | ✅ 최대 회전 |
| `lowering` | ✅ 팔 내리는 구간 | ✅ 팔/다리 내리는 구간 | ✅ 다리 내리는 구간 | — |
| `transition` | ✅ | ✅ | ✅ | ✅ |
| `unknown` | ✅ | ✅ | ✅ | ✅ |
| 전용 phase | — | — | — | turning_right/left, center |

## 4. 정상/비정상 기준 체계

### 4.1 편차값 계산 원리

모든 임계값은 **DTW feature error** 기반 0~1 정규화 값이다.

```
feature_error = |사용자 특징값 - 참조 특징값| / 정규화 스케일
```

- 0에 가까울수록 참조 동작과 일치
- 1에 가까울수록 편차가 큼
- 편차값이 임계값을 초과하고, 해당 특징이 상위 편차 항목에 포함될 때만 오류로 판정

### 4.2 심각도 (Severity) 등급

| 심각도 범위 | 등급 | 피드백 처리 |
|---|---|---|
| 0.00 ~ 0.34 | 경미 | 피드백 미발송 (emit_threshold 미달) |
| 0.35 ~ 0.59 | 보통 | 쿨다운(2.5초) 적용 후 발송 |
| 0.60 ~ 0.79 | 심각 | 우선 발송 |
| 0.80 ~ 1.00 | 매우 심각 | 최우선 발송 |

> emit_threshold = 0.35, cooldown_sec = 2.5 (RealTimeFeedbackRouter 기본값)

### 4.3 정상 동작 판정 기준 (요약)

| 지표 | 정상 기준 | 비정상 |
|---|---|---|
| posture_similarity | ≥ 80% (SLR은 ≥ 78%) | < 기준값 |
| motion_similarity | ≥ 85% | < 기준값 |
| 개별 feature_error | < 운동별 임계값 (3절 참고) | ≥ 임계값 |
| 감지된 error_type 수 | 0개 | 1개 이상 |

## 5. 라벨링 가이드 (데이터 수집 시 적용)

### 5.1 영상 1개(세션 1개)에 부여할 라벨 구조

```json
{
  "session_id": "record_20260616_143022_bird_dog",
  "exercise": "bird_dog",
  "annotator": "...",
  "overall_label": "normal",
  "frames": [
    {
      "frame_index": 0,
      "ts": 1718500000.123,
      "phase": "ready",
      "keypoints": { "5": {"x":..., "y":...}, ... },
      "deviations": [],
      "label": "normal"
    },
    {
      "frame_index": 15,
      "ts": 1718500000.623,
      "phase": "raising",
      "keypoints": { ... },
      "deviations": ["balance_gap"],
      "label": "abnormal"
    }
  ]
}
```

### 5.2 overall_label 기준

| 라벨 | 기준 |
|---|---|
| `normal` | 전 구간에서 error_type 미감지, posture_similarity ≥ 기준값 |
| `minor_error` | error_type 1~2개, severity < 0.6, 동작 완료 |
| `major_error` | error_type 1개 이상 severity ≥ 0.6, 또는 error_type 3개 이상 |
| `incomplete` | 동작이 끝나지 않음 (rep_finished 미발생) |
| `invalid` | unknown phase가 50% 이상, 또는 필수 관절 미감지 |

### 5.3 라벨링 우선순위 원칙

1. **phase를 먼저 부여한다.** 관절 좌표 없이 phase만 판단 가능한 경우도 있다.
2. **deviation은 raising/peak/lowering 구간에서만 부여한다.** idle/ready 구간의 편차는 준비 자세 문제로 별도 처리한다.
3. **posture_quality_low는 다른 deviation이 없을 때만 부여한다.** 구체적인 원인이 특정된 경우 posture_quality_low는 사용하지 않는다.
4. **한 프레임에 복수 deviation을 부여할 수 있다.** 단, 같은 신체 부위의 중복 편차는 severity가 높은 것 하나만 유지한다.
