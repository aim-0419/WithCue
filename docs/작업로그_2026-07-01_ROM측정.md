## 배경

자세분석(POSTURE CHECK) 세션에서 부위별 최대 가동범위(ROM)를 측정해 `rom` 객체로 반환하고, 프론트가 이를 localStorage에 저장한다. 코칭 쪽(참석자3/팀장)은 이 `rom` 값을 읽어 개인 ROM 대비 % 기준으로 rep 카운팅·피드백을 만든다. 따라서 **변수명은 P2-9 문서 철자 그대로가 팀 공용 계약**이다.

- 촬영: 정면 단일 카메라 + 3D 좌표
- 측정 부위: 어깨 → 목 → 무릎 (허리/코어 제외)
- 주형 범위 = 측정 → 각도 → `rom` 반환까지. 실제 `localStorage.setItem`과 코칭 % 로직은 범위 밖.

- 실제 카메라·서버 없이 mock 좌표로 각도 계산·상태 전이·rom 키를 단위 검증.

- 백엔드는 8018 포트(`uvicorn app.main:app --port 8018 --reload`), 프론트는 `npm run dev`(vite). `rom` 왕복은 `/ws/dtw/{exercise}?rom=...` 쿼리로 이미 배선됨.
