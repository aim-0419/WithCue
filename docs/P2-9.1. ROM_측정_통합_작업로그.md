## 완료 작업 (mock 검증 통과)

### 1. ROM 파일 저장 중앙화
- [motion_service.py](../backend/app/services/motion_service.py) — 프로세서 결과에 `rom`이 있으면 **세션당 1회** `backend/app/assets/rom_results/rom_<부위>_<시각>.json`으로 저장 + 로그. `_rom_saved` 가드로 매 프레임 중복 저장 방지.
- [shared/measurement.py](../backend/app/exercises/shared/measurement.py) — 어깨(MeasurementProcessor)에 있던 **중복 파일 저장 제거**(중앙으로 이관), 미사용 `_rom_saved` 플래그 정리.
- 효과: 어깨·목·무릎·전체 **어느 걸 측정해도** MotionService 한 경로를 타므로 파일이 남음. 프론트 저장 없이도 값 검증 가능(팀장 요청 반영).

### 2. 무릎 라우팅 수정
- [api.py](../backend/app/api/api.py) — 프론트가 `knee_left`/`knee_right`를 보내는데 기존 라우팅은 `parts=="knee"`라 **새 무릎 플로우가 호출 안 되던 문제** 수정.
- `parts in ("knee","knee_left","knee_right")` → `KneeROMMeasurementProcessor`. 좌/우 어느 쪽을 눌러도 앉기→양다리 펴기→일어서기 전체 STS 플로우 실행.
- (설계 메모) UI는 무릎을 좌/우로 나누지만 P2-9 무릎은 양다리 한 세션이라, 백엔드에서 좌/우 모두 같은 플로우로 보내 UI와 문서를 맞춤. UI를 무릎 단일 카드로 합치는 건 프론트 조율 사항.

### 3. 전체(전신) 통합
- [shared/measurement.py](../backend/app/exercises/shared/measurement.py) — `FullBodyMeasurementProcessor` 추가. P2-9 순서(**어깨 → 목 → 무릎**)대로 하위 3개 프로세서를 순차 실행 → 각 부위 rom 병합 → `FULL_BODY` finished로 반환.
- 하위 프로세서 유형이 서로 달라(어깨=stage 체인, 목·무릎=상태머신) 기존 MeasurementProcessor 스케줄로는 통합 불가 → 오케스트레이터로 해결.
- 중간 완료 rom은 제거해 **중앙 저장이 최종 통합 rom만** 1회 저장(`rom_full_body_*.json`).
- [api.py](../backend/app/api/api.py) — `parts` 없음(전체 정밀 검사) → `FullBodyMeasurementProcessor` 라우팅.

### 4. 무릎 자세 확장 — 서서 무릎 들기 추가 (팀장 지시)
- [straight_leg_raise/measurement.py](../backend/app/exercises/straight_leg_raise/measurement.py) — 무릎 플로우에 `LEFT_RAISE`/`RIGHT_RAISE` 단계 추가.
- 새 흐름: 앉기 → 좌 무릎 펴기 → 우 무릎 펴기 → 일어서기 → **좌 다리 들기 → 우 다리 들기** → 종료.
- 무릎 시작 자세는 **앉아서 시작(SIT)** 으로 확정.
- 측정: 서서 다리 들 때 **고관절 각도(shoulder-hip-knee 원각도)**. 선 자세 ~180°, 다리 들수록 작아짐 → **가장 든 순간의 각도(최솟값)** 저장 (팀장 확정: 선 자세 180 기준).
- rom 키: `straight_leg_raise_left_max` / `straight_leg_raise_right_max` (이미 DEFAULT_ROM에 존재).

## 남은 작업

1. **실측 튜닝 (카메라 필요)** — 무릎 각도 임계값(`SIT_KNEE_MAX=130/EXTEND_MIN=150/STAND_MIN=150`), 서서 다리 들기 임계값(`RAISE_ENTER=160/RAISE_EXIT=170`), 목 3D 회전 임계값(`LEFT_ENTER=-20` 등). 팀장 카메라 테스트로 조정.
2. **프론트 localStorage 저장 (프론트 담당)** — 측정 완료 시 `data.rom`을 저장하는 코드. 현재는 백엔드가 파일로 남겨 검증만 가능.
3. **무릎 UI 조율 (프론트)** — 좌/우 분리 → 무릎 단일 카드로 합칠지.
4. **새 상태 음성 매핑 (프론트)** — 무릎(`sit_hold/left_extend/right_extend/stand/left_raise/right_raise`), 전체(`transition`) 등.
5. **DEFAULT_ROM `straight_leg_raise` 기본값 (팀장 확인 대기)** — 현재 70인데 원각도(~120~180) 스케일과 안 맞음. 폴백값 조정 필요.
