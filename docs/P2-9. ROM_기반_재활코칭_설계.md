# P2-9. ROM 기반 재활 코칭 설계

## 개요

자세 분석(POSTURE CHECK) 세션에서 부위별 최대 가동범위(ROM)를 측정하고,
측정된 ROM을 기준으로 재활 코칭의 rep 카운팅 임계값과 피드백을 개인화한다.
고정 각도 기준이 아닌 개인 ROM 대비 % 기준을 사용하므로,
가동범위가 일반인보다 좁은 어르신도 운동이 카운팅된다.

**전체 촬영 방향: 정면 단일 카메라 (3D 좌표 사용)**
**측정 부위: 어깨 → 목 → 무릎 순서로 진행 (허리/코어 제외)**

---

## 1. 자세 분석 세션 설계

### 1-1. 어깨 (정면 촬영 + 3D 좌표)

#### 동작: 양팔 앞으로 들어올리기 → 앞으로 내리기 (만세 자세)
- 양팔을 정면으로 최대한 들어올렸다가 동일 경로로 내림
- 좌/우 동시 진행

| Phase | 움직임 | 사용 관절 | 계산 각도 |
|---|---|---|---|
| 올라가는 중 | 어깨 굴곡 (shoulder flexion) | shoulder(5,6) · hip(11,12) · wrist(9,10) | 3D trunk 벡터(hip→shoulder)와 arm 벡터(shoulder→wrist) 간 각도 |
| 내려가는 중 | 어깨 굴곡 복귀 | 동일 | 동일 (대칭적으로 감소) |
ㄹ고점 이후 하강 → 내려가는 phase

#### localStorage 저장 변수 (어깨)

```json
{
  "shoulder_left_flexion_max":  150,
  "shoulder_right_flexion_max": 155
}
```

- `flexion_max`: 올라가는 구간에서의 최대 굴곡각 (3D 벡터 기준)

---

### 1-2. 목 (정면 촬영 + 3D 좌표)

#### 동작: 좌우 회전 (1회 = 한쪽 → 정면 → 반대쪽 → 정면)

3D 좌표를 사용하면 카메라와의 각도 차이나 고개가 약간 숙여진 경우에도 정확한 회전각을 측정할 수 있다.
2D 픽셀 좌표만 쓸 경우 카메라 정면을 바라보지 않는 순간 오차가 커진다.

| 측정값 | 사용 관절 | 계산 방법 |
|---|---|---|
| 좌측 최대 회전각 | nose(0) · left_shoulder(5) · right_shoulder(6) | 3D 코 좌표의 어깨 중심 대비 수평(X·Z 평면) 편차로 회전각 계산 |
| 우측 최대 회전각 | 동일 | 동일, 반대 방향 |

기존 neck_rotation feature의 `neck_turn_angle` 값을 3D 기반으로 업데이트해 사용.

#### localStorage 저장 변수 (목)

```json
{
  "neck_rotation_left_max":  65,
  "neck_rotation_right_max": 70
}
```

---

### 1-3. 무릎/하지 (정면 촬영 + 3D 좌표)

#### 동작 1: STS (Sit To Stand) - 의자에서 앉았다 일어나기

하지 기능 전반을 평가하는 표준 임상 기능 검사.
고관절·무릎 신전 기능과 대퇴사두근 힘을 확인한다.

| 측정값 | 사용 관절 | 계산 방법 |
|---|---|---|
| 앉은 자세 무릎 굴곡각 | hip(11,12) · knee(13,14) · ankle(15,16) | 3D hip→knee→ankle 각도 (앉았을 때 기준값) |
| 앉은 자세 고관절 굴곡각 | shoulder(5,6) · hip · knee | 3D shoulder→hip→knee 각도 |
| STS 완료 여부 | 전체 관절 | 무릎이 완전히 펴진 서있는 자세 도달 여부 |

**phase 감지:** 엉덩이(hip) Y값 상승 시작 → 일어나는 중, Y값 안정화 → 완료

#### 동작 2: 앉아서 무릎 펴기 (Seated Knee Extension) - 좌/우 각각

의자에 앉은 상태에서 한 발씩 무릎을 최대한 뻗기.
고관절 90° 굴곡 상태에서의 무릎 신전 능력 = 햄스트링 유연성 직접 측정.
하지 직거상의 핵심 제한 요소를 측정하는 자세.

| 측정값 | 사용 관절 | 계산 방법 |
|---|---|---|
| 좌측 최대 무릎 신전각 | left_hip(11) · left_knee(13) · left_ankle(15) | 3D hip→knee→ankle 각도 최댓값 |
| 우측 최대 무릎 신전각 | right_hip(12) · right_knee(14) · right_ankle(16) | 3D hip→knee→ankle 각도 최댓값 |

**phase 감지:** 발목(ankle) Y값 상승 → 올라가는 phase, 최고점 = ROM

#### localStorage 저장 변수 (무릎/하지)

```json
{
  "knee_flexion_at_sit_left":          92,
  "knee_flexion_at_sit_right":         90,
  "sts_completed":                   true,
  "seated_knee_extension_left_max":   168,
  "seated_knee_extension_right_max":  165
}
```

- `knee_flexion_at_sit`: 앉은 자세 기준 무릎 굴곡각 (동작 기준선)
- `sts_completed`: STS 성공 여부
- `seated_knee_extension_max`: 앉아서 무릎 편 최대 각도 (햄스트링 유연성 지표, 하지 직거상 캘리브레이션에 사용)

---

### localStorage 전체 구조

```json
{
  "rom": {
    "shoulder_left_flexion_max":          150,
    "shoulder_right_flexion_max":         155,

```

## 2. 재활 코칭 적용

### 2-1. % 구간 기반 피드백 방향

> **주의:** 아래 % 구간 경계값은 임의 설정이다. 의학적 근거가 없으므로 부위·동작별로 별도 설계가 필요하다.
> 공통 기준이 아닌 각 동작(2-2, 2-3, 2-4)에서 개별적으로 명시한다.

**공통 원칙 (방향성):**
- 개인 ROM 최고값 대비 너무 낮은 구간 → rep 미카운팅 + "더 올려보세요" 류 피드백
- 적정 구간 → rep 카운팅, 피드백 없음 또는 칭찬
- 개인 ROM 최고값 근처 또는 초과 → "통증이 느껴지면 그만 올리세요" 안전 피드백 고려

**각 동작별 세부 기준은 2-2 ~ 2-4에서 개별 정의한다.**
(구간 경계값, 피드백 문구, 음성 출력 여부 등은 임상 피드백 후 결정 예정)

---

### 2-2. 어깨 전방 거상 (shoulder_front_raise)

**사용 ROM:** `shoulder_{side}_flexion_max`

| 항목 | 기존 (고정값) | 변경 후 (개인화) |
|---|---|---|
| raise_threshold (up 인식) | 110° | `flexion_max × 0.6` |
| down_threshold (down 인식) | 90° | `flexion_max × 0.4` |
| min_peak_angle | 110° | `flexion_max × 0.6` |
| 60~80% 피드백 조건 | - | `flexion_max × 0.6 ~ flexion_max × 0.8` |

예시 (flexion_max = 150°):
- raise_threshold = 90°, down_threshold = 60°
- 90~120° 구간이면 카운팅 + "더 올릴 수 있어요"
- 120° 이상이면 카운팅, 피드백 없음

---

### 2-3. 목 좌우 돌리기 (neck_rotation)

**사용 ROM:** `neck_rotation_left_max`, `neck_rotation_right_max` (좌/우 각각 적용)

| 항목 | 기존 (고정값) | 변경 후 (개인화) |
|---|---|---|
| turn_threshold (회전 시작 인식) | 9° | `각 방향 max × 0.3` |
| min_peak_angle | 15° | `각 방향 max × 0.5` |
| 60~80% 피드백 조건 | - | `각 방향 max × 0.6 ~ × 0.8` |

---

### 2-4. 하지 직거상 (straight_leg_raise)

**사용 ROM:** `seated_knee_extension_{side}_max`

하지 직거상 processor는 누운 자세 기준 shoulder→hip→knee 각도를 측정한다.
다리가 바닥에 있을 때 ~180°, 들어올릴수록 각도 감소.

`seated_knee_extension_max`는 고관절 90° 굴곡 상태에서의 최대 무릎 신전각으로,
햄스트링 유연성을 직접 반영한다.
값이 클수록(180°에 가까울수록) 하지 직거상을 더 높이 들 수 있다.

**변환 공식:**
```
raise_threshold  = 180° - (seated_knee_extension_max - 90°) × 0.7
min_peak_flexion = raise_threshold
down_threshold   = raise_threshold + 15°
```

예시 (seated_knee_extension_max = 168°):
- raise_threshold  = 180 - 78 × 0.7 = 180 - 54.6 ≈ 125°
- min_peak_flexion = 125°
- down_threshold   = 140°

예시 (seated_knee_extension_max = 140° - 햄스트링 타이트):
- raise_threshold  = 180 - 50 × 0.7 = 180 - 35 ≈ 145°
- down_threshold   = 160°

| 항목 | 기존 (고정값) | 변경 후 (개인화) |
|---|---|---|
| raise_threshold | 150° | `180 - (max - 90) × 0.7` |
| min_peak_flexion | 150° | 동일 |
| down_threshold | 160° | `raise_threshold + 15` |

## 3. 결과 페이지 전달값

### 자세 분석 결과 페이지

| 값 | 설명 |
|---|---|
| `rom` | 측정된 ROM 전체 (부위별, 좌/우) |
| `measured_at` | 측정 시각 |
| 좌우 비대칭 비율 | 예: 좌측 굴곡 150° / 우측 굴곡 120° → 비대칭 20% |
| `sts_completed` | STS 성공 여부 (하지 기능 지표) |

### 재활 코칭 결과 페이지

| 값 | 설명 |
|---|---|
| `rep_count` | 완료된 rep 수 |
| `rep_quality` | rep별 품질 구간 (60~80% / 80~100% / 100%+) |
| `avg_quality_pct` | 평균 ROM 달성률 (%) |
| `rom_baseline` | 이번 세션에 사용된 ROM 기준값 |

---

## 4. ROM 측정값 저장 정책

- 가장 최근 자세 분석 세션의 측정값을 localStorage에 유지한다.
- 새로운 자세 분석 세션이 시작되면 기존 `rom` 전체를 초기화하고 새로 측정된 값으로 덮어쓴다.
- 유효기간 별도 없음. "언제 측정했는가"는 `measured_at`으로 확인.

---

## 5. 미결 사항

- 하지 직거상 변환 계수(×0.7) 임상 검증 필요
- 각 동작별 피드백 구간 경계값(%) 임상 피드백 후 결정 필요
- 목 3D 회전각 계산 구현 (현재 neck_rotation feature는 2D 기반)
- 버드독 ROM 측정 자세 교수님 피드백 후 결정
